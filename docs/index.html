Длинный текст в плашке

Где в справочнике «Плашки с текстом» - CSS блока, правило .pad в начале шаблона.

В шаблоне Content_SEO под каждую строку карточек отведено 88 px. На телефоне шириной 390 px текст из примера занял 120 px и вышел за голубой фон. Я оставил 88 px как минимум. С тем же текстом плашка выросла до 152 px, и следующая началась ниже.

Шаблон Content_SEO
grid-auto-rows: 88px;
В справочнике
grid-auto-rows: minmax(88px, auto);

Сетка для разного числа карточек

Где в справочнике «Общие стили» - CSS сетки .grid-auto. В HTML каждого карточного блока число элементов задано классом grid-auto--N.

В шаблонах Content_SEO для текстовых плашек есть раскладки на четыре, пять и шесть пунктов. На снимке я оставил три пункта и использовал базовый класс pad. Каждый пункт занял одну из шести колонок. В справочнике редактор указывает число карточек в классе сетки. Для трёх пунктов правило grid-auto--3 отдаёт каждому четыре из двенадцати колонок. Такие раскладки заданы для наборов от одного до десяти.

Шаблон Content_SEO
.pad {    grid-gap: 24px;    grid-template-columns:repeat(6, 1fr);    grid-auto-rows: 88px;    display: grid}
В справочнике
.grid-auto {    display: grid;    grid-template-columns: repeat(12, 1fr);    gap: 24px;}.grid-auto--3  > * { grid-column: span 4; }

Свои стрелки у каждого слайдера

Где в справочнике «Слайдер» - HTML контейнера .slider-block, CSS в начале шаблона и JavaScript после разметки. Это относится ко всем трём вариантам шапки.

В шаблоне Content_SEO названия стрелок и точек привязаны к одному слайдеру. Для второго редактору нужно согласовать новые имена в HTML и скрипте. Я собрал слайды, стрелки и точки в один блок. Скрипт находит элементы внутри него, поэтому оба слайдера можно вставить с одинаковыми классами.

Шаблон Content_SEO
navigation: {    nextEl: ".js-next-stambul",    prevEl: ".js-prev-stambul",},
В справочнике
navigation: {    nextEl: block.querySelector(".slider__next"),    prevEl: block.querySelector(".slider__prev"),},

Зацикливание тоже зависит от наполнения. При четырёх видимых карточках оно включается с восьми слайдов. Если вся подборка уже видна, стрелки и точки скрываются.

Шаблон Content_SEO
loop: true,
В справочнике
loop: slidesCount >= perView * 2,watchOverflow: true,

Как ведут себя две подборки на одной странице

Допустим, в подборке отелей пять слайдов и задано data-per-view="4", а в подборке экскурсий - три слайда и data-per-view="3". На компьютере видны четыре отеля. Стрелка открывает пятый и управляет только отелями. Все три экскурсии уже видны, поэтому у этой подборки скрыты стрелки и точки.

При ширине 768–1023 px в обеих подборках видно по два слайда, ниже 768 px - по одному. Точки появляются, когда есть куда листать. Сами стрелки скрыты стилями до 768 px включительно. Зацикливание зависит от заданного числа карточек на компьютере: при значении 4 пять слайдов листаются до конца, а начиная с восьми - по кругу.

Как связаны разметка, стили и скрипт

В HTML я добавил общую обёртку с настройкой количества видимых карточек. Точки переключения остались внутри Swiper, а стрелки расположены рядом с ним, но в пределах общей обёртки. Через CSS стрелки привязаны к этой обёртке и вынесены за края слайдера. Если все карточки помещаются на экране, класс slider-block--locked скрывает элементы управления.

Скрипт дожидается полной загрузки страницы CMS, находит все слайдеры и инициализирует каждый только один раз. События lock и unlock позволяют автоматически скрывать или показывать управление при изменении ширины экрана. Если количество видимых карточек не указано через data-per-view, по умолчанию отображаются три. Подключение Swiper 11 осталось из шаблона Content_SEO. Размер и цвет точек настраиваются в «Общих стилях», а их отображение зависит от состояния самого слайдера.

async function hostReactAppReady(
    selector = "#__next > div",
    timeout = 500,
) {
    return new Promise((resolve) => {
        const waiter = () => {
            const host_el = document.querySelector(selector);
            if (host_el?.getBoundingClientRect().height) {
                resolve();
            } else {
                setTimeout(waiter, timeout);
            }
        };
        waiter();
    });
}

hostReactAppReady().then(() => {
    document.querySelectorAll(".slider-block").forEach((block) => {
        const swiperEl = block.querySelector(".swiper");

        const perView = parseInt(block.dataset.perView || "3", 10);
        const slidesCount = swiperEl.querySelectorAll(".swiper-slide").length;
        const swiper = new Swiper(swiperEl, {

            spaceBetween: 24,

            watchOverflow: true,

                    spaceBetween: 24,

            on: {

                    block.classList.add("slider-block--locked");
                },
                unlock() {
                    block.classList.remove("slider-block--locked");
                },
            },
        });

});

Один клик по вопросу в FAQ

Где в справочнике «Раскрывашка (аккордеон) с микроразметкой» и «SEO ссылки» - JavaScript в конце каждого шаблона, внутри toggles.forEach.

FAQ и списки SEO-ссылок используют одинаковые раскрывающиеся элементы. Оба скрипта ищут их по всей странице. Если дважды назначить действие на один заголовок, первый обработчик откроет ответ, а второй тем же кликом его закроет. В обоих шаблонах я добавил отметку: если этот элемент уже подключён, скрипт его пропускает.

Шаблон Content_SEO
const header = toggle.querySelector(".js-toggle-header");
В справочнике
if (toggle.dataset.toggleBound) return;toggle.dataset.toggleBound = "1";const header = toggle.querySelector(".js-toggle-header");

Меню на телефоне

Где в справочнике «Навигация» - JavaScript блока, функция onScroll.

Если в меню много разделов, ссылки занимают несколько строк. В шаблоне Content_SEO меню закрепляется при прокрутке. В справочнике на экранах до 768 px оно уходит вверх вместе со страницей. Ссылки по-прежнему ведут к разделам, а под текст остаётся больше места.

anchors.classList.add('anchors--fixed');placeholder.style.display = '';
В справочнике
if (window.matchMedia('(max-width: 768px)').matches) {    if (anchors.classList.contains('anchors--fixed')) {        anchors.classList.remove('anchors--fixed');        placeholder.style.display = 'none';    }    return;}
